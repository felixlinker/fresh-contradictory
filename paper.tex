\title{Rule Variant Restrictions for the Tamarin Prover}

\author{Felix Linker\orcidID{0009-0000-7886-4480}}
\institute{Department of Computer Science, ETH Zurich, Zürich, Switzerland
\email{flinker@inf.ethz.ch}}

\maketitle

\begin{abstract}
  We introduce an optimization to the Tamarin prover that reduces its search space.
  The optimization applies to protocol models that use equational theories with cancellative operators, for example, when modelling Diffie-Hellman groups or bilinear pairings.
  We prove the optimization's soundness and evaluate its performance.
\end{abstract}


\section{Introduction}

The Tamarin prover \cite{CAVtamarin,CSFtamarin} is a state-of-the-art model checker for security protocols.
It was originally developed in two doctoral theses \cite{TamarinThesisInduction,TamarinThesisConstraintSolving}, supervised by David Basin.
In this work, I will present an optimization to the Tamarin prover that I identified while formally verifying the SecureDrop protocol \cite{SecureDrop}.
I worked on the SecureDrop project while I was finalizing my doctoral thesis, also supervised by David.
While the optimization may seem conceptually simple, I would not have been able to identify it nor been able to prove its soundness prior to my doctorate.
This work showed me how much David had taught me during my doctorate, which is why I would like to dedicate this work to him.

Tamarin operates in the so-called \emph{symbolic model}, in which cryptography is modelled by an \emph{equational theory}.
Concretely, cryptographic messages are represented by terms and uninterpreted functions, and the effects of cryptographic operations by equations on these terms.
Tamarin reasons modulo this equational theory but only considers equational theories with specific properties.
These properties allow Tamarin to compute the finite set of \emph{variants} associated to a term, which represent all potential shapes the term might take.
Unifying two terms modulo a full equational theory, including associativity and commutativity, can be implemented by unifying the two terms' variants modulo associativity and commutativity only, which greatly simplifies Tamarin's proof search.

Variants extend to more complex constructs, like protocol rules, and Tamarin computes protocol rule variants during a precomputation phase.
In this paper, we prove that certain rule variants correspond to protocol rule instances that could never occur in a run of a protocol.
Thus, any constraint system containing them can be considered contradictory and one can safely ignore such rule variants.
We experienced significant performance improvements when using this pruning mechanism, in particular when modelling protocols that use Diffie-Hellman group operators.
Our optimization has been integrated into Tamarin's code base.\footnote{%
  See \url{https://github.com/tamarin-prover/tamarin-prover/pull/763}.
}

\section{Rule Variant Restrictions}
\label{sec:theory}

Our optimization applies to theories that use operators which can cancel out and lead to multiple rule variants.
For example, Tamarin provides built-in support for an equational theory modelling Diffie-Hellman groups.
That theory supports the operators $(\cdot)/2$ (multiplication), $\circ^\circ/2$ (exponentiation), $\circ^{-1}/1$ (inverse), and $\epsilon/0$ (neutral element) as well as, in particular, the following equations:
\begin{gather*}
  x \cdot x^{-1} = \epsilon \\
  x^\epsilon = x
\end{gather*}

Our optimization was motivated by rules such as the following:
$$[  \Fr(\ofsort{x}{\fresh}), \In(m) ] \rightarrow [ \Out(m^x) ].$$

In the above rule, a protocol participant receives some message $m$ over the network, raises it to the power of a fresh, unguessable value $x$, and sends the result over the network.
During precomputation, Tamarin will consider the case in which raising $m$ to $x$ might cancel out, which it represents with the rule variant:
$$[ \Fr(\ofsort{x}{\fresh}), \In(z^{\ofsort{x}{\fresh}^{-1}}) ] \rightarrow [ \Out(z) ].$$

Note, though, that constructing $m = z^{\ofsort{x}{\fresh}^{-1}}$ requires knowledge of $x$ to raise $z$ to $x$'s inverse.
The value $x$, though, is freshly introduced in the above rule.
Thus, constructing $m$ requires $x$ to be used before it is introduced, which is impossible.

In the following, we introduce \emph{fresh-contradictory rule variants}, which formalize the above intuition.
Fresh-contradictory rule variants use a fresh value before it is introduced.
We show that one can remove such variants from a protocol model without changing the model's associated set of normal-form dependency graphs.

\begin{definition} \label{def:fresh-contradictory}
  Let $r = [ p_1, \dots, p_n] \lrule{\dots} [\dots]$ be a protocol rule and let $\variants{r}^\R = \{(r_i, \tau_i)\}_{1 \leq i \leq m}$ be a complete set of associated variants for a rewriting system $\R$ and associative and commutative equations $AX$.
  A variant $(r_i, \tau_i) \in \variants{r}^\R$ is \emph{fresh-contradictory} if $r$ has two distinct premises $p_k = \fact{F}(\dots, t, \dots)$ ($\fact{F} \neq \Fr$) and $p_l = \Fr(x)$ such that $x\tau_i \sqsubseteq t\tau_i \normf^\R$.
\end{definition}

We write $\variants{r}^{\R,\bot} \subseteq \variants{r}^\R$ for the fresh-contradictory variants of a rule $r$ and extend this notation to sets of multiset rewriting rules.

\begin{lemma} \label{lem:ndg-eq}
  For every protocol model $(R, E)$ where $\R^\simeq \cup AX$ is an equational presentation of $=_E$ and $AX$ only contains equations for associativity and commutativity:
  \begin{multline*}
    \{ dg\normf^\R \mid dg \in \dgraphs_{AX}(\variants{R}^\R) \} = \\ \{ dg\normf^\R \mid dg \in \dgraphs_{AX}(\variants{R}^\R \setminus \variants{R}^{\R,\bot})\}.
  \end{multline*}
\end{lemma}

\begin{proof}
  Let
  \begin{align*}
    NDG & := \{ dg\normf^\R \mid dg \in \dgraphs_{AX}(\variants{R}^\R) \} \\
    NDG_{\neg\bot} & := \{ dg\normf^\R \mid dg \in \dgraphs_{AX}(\variants{R}^\R \setminus \variants{R}^{\R,\bot})\}.
  \end{align*}
  It is clear that $NDG_{\neg\bot} \subseteq NDG$.
  We show that $NDG \subseteq NDG_{\neg\bot}$ by contradiction.
  Suppose that there is a dependency graph $dg = (I, D) \in NDG \setminus NDG_{\neg\bot}$.
  By assumption, we know that all rule instances $ri \in I$ are $\normf^\R$-normal (as $dg$ is $\normf^\R$-normal).
  Thus, by the finite variant property, we know that for each rule instance $ri \in I$ there must be a rule variant $(r, \tau) \in \variants{R}^\R$ so that $ri =_{AX} r\sigma$ for some substitution $\sigma$ (note that $r$ is $\normf^\R$-normal by definition).
  There must be some rule instance $ri$ for which its associated variant $(r, \tau)$ (as per above) is in $\variants{R}^{\R,\bot}$.
  If not, $dg$ would be in $NDG_{\neg\bot}$.
  We fix such a rule instance $ri$ and associated variant $(r, \tau)$.

  As $r$ is a fresh-contradictory variant, there must be some fresh variable $x$ and term $t$ occurring in $r$ such that $x \sqsubseteq t$ and $x$ is introduced in $r$, i.e., $r$ has a $\Fr(x)$ premise.
  Because $ri =_{AX} r\sigma$ and because equations in $AX$ can never remove terms, we have that \begin{enumerate*}[label=(\roman*)]
    \item $\Fr(x\sigma)$ occurs in $ri$,
    \item $t\sigma$ occurs in $ri$, and
    \item $x\sigma$ occurs in $t\sigma$.
  \end{enumerate*}
  As $ri$ is $\normf^\R$-normal (cannot be reduced), $t\sigma$ in $ri$ must have been constructed using $x\sigma$.
  Therefore, there must be another rule instance in $dg$ that introduces $x\sigma$ to construct $t\sigma$ and that thus also contains a premise $\Fr(x\sigma)$.
  This, however, contradicts that instances of $\RFresh$ are unique.
\end{proof}

We can use this lemma to specialize Theorem~\ref{thm:reasoning-mod-ax} to obtain the following theorem.

\begin{theorem} \label{thm:reasoning-mod-fresh}
    For every guarded trace property $\varphi$ and protocol model $(R, E)$ where $\R^\simeq \cup AX$ is an equational presentation of $=_E$ and $AX$ only contains equations for associativity and commutativity:
    \begin{multline*}
      R \tsatE^\forall \varphi \iff \\
        \{ \trace(dg) \mid dg \in \dgraphs_{AX}(\variants{R}^\R \setminus \variants{R}^{\R,\bot}), dg~\text{is}~\normf^\R\text{-normal} \} \tsat{AX}^\forall \varphi.
    \end{multline*}
\end{theorem}

\begin{proof}
  This follows directly from Theorem~\ref{thm:reasoning-mod-ax} and Lemma~\ref{lem:ndg-eq}.
\end{proof}

Theorem~\ref{thm:reasoning-mod-fresh} allows us to prune all fresh-contradictory variants during Tamarin's precomputations.

\section{Conclusion}

In this work, we presented an optimization to the Tamarin prover, proved its soundness, and evaluated its performance.
To reason efficiently, Tamarin precomputes rule variants.
Our optimization identifies redundant rule variants, which we call fresh-contradictory and which can be omitted from precomputation and thus also from proof search.

\paragraph{Future Work}
We identified the presented optimization during proof search, when we observed that the adversary would use fresh values before they are introduced.
Tamarin already recognizes the use of fresh values before they are introduced as a contradiction, but only when they do not occur below a reducible function symbol such as exponentiation.
For future work and as an alternative to our optimization, one could explore lifting or relaxing that restriction.
